# Software Engineering, QA, Security and Network Modeling Portfolio

This repository contains academic artifacts related to software engineering analysis, process modeling, quality assurance, software testing, security, and computer-network simulation.

## Contents

- UML diagrams and system models.
- BPMN process diagrams.
- Use-case specifications and requirements.
- Test cases and quality assurance documentation.
- Foundational security analyses.
- Cisco Packet Tracer `.pkt` network simulations.

## Skills demonstrated

- Requirements analysis.
- UML and BPMN modeling.
- Use-case and test-case design.
- Software quality assurance.
- Risk and security analysis.
- Network topology design.
- IP addressing, connectivity testing, and troubleshooting.
- Technical documentation.

## Tools and formats

Artifacts may include files created with Cisco Packet Tracer, Draw.io, Bizagi Modeler, Microsoft Office, and similar modeling tools.

GitHub cannot preview `.pkt` files directly. Download them and open them with Cisco Packet Tracer.

## Academic context

The materials were developed as academic exercises and demonstrate the practical application of software engineering, testing, security, and networking concepts.
